論点マップの別案試作同じ意見のデータを、3 つの別の切り口で整理してみる

活動と論点マップの目的

特定の政策提言や一つの結論へ誘導することはしません。産業界の方も一般の市民も、それぞれの立場と関心のレベルで、問題を自分事として考えられる場と情報を提供します。

「それぞれのレベルで」考えられるように、入口の違う 3 つの整理を試作しました。いずれも現行の論点マップと同じスプレッドシートの意見を読み込んでいます。現行のマップはそのまま残します。

A

3階層＋キーワード

エネルギー → S+3E → 技術 の 3 段だけで全体を見渡し、細かい論点（放射性廃棄物、再稼働など）は意見に付くキーワードにする。階層が浅いので迷いにくい。

向いている人: はじめて全体を見る人、説明の場 開く → B

3つの軸で並べる

意見に「評価軸・技術・主体」の 3 種類のタグを付け、1 つの軸で絞り込む（例: 経済効率性）と、残り 2 軸のタグで意見どうしの関係がネットワーク／格子で見える。

向いている人: 産業界・専門家など、特定の観点から深く比べたい人 開く → C

暮らしから見る

電気代やスマホの充電など「見えている」ものから、素材を作るエネルギーや燃料の輸入など「見えていない」ものへ。生活者の認識を同心円で表し、論点・意見につなぐ。

向いている人: 一般の市民、生徒、ワークショップ 開く →
