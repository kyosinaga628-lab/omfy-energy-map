# omfy energy map

@omfy の論点マップ（エネルギー）。論点の構造と、メンバーがハンドルネームで書いた意見を一枚で見せる公開ワークスペース。

- 編集面: Google スプレッドシート（メンバーのみ）
- 探索用マップ: [Kumu（公開）](https://embed.kumu.io/60df0d9cd82ddb8ef5518e544d696fa7)
- 公開サイト: このリポジトリの `site/`（GitHub Pages、Phase 1 で公開）
- データのスナップショット: `data/latest/`（毎晩 03:00 JST に自動取得。差分は履歴で見られる）

## データ

| ファイル | 元のシート | 内容 |
|---|---|---|
| `data/latest/nodes.csv` | 論点 | ID、論点名、種別、親論点、関係する評価軸（○）、問い、状態 |
| `data/latest/opinions.csv` | 意見 | 記入日、ハンドル、論点、記入者属性、立場、根拠タイプ、主張、補足 |
| `data/latest/roles.csv` | 属性マスタ | 記入者属性の一覧、説明、集約先 |

実名・連絡先は含まれない（会員名簿は非公開の別ファイルで、このリポジトリには接続しない）。

## 免責

掲載された意見は記入者個人の見解であり、@omfy の公式見解ではない。論点構造はメンバーの合意に基づく整理であり、網羅性・中立性は努力目標である。

## 運用

- 意見はスプレッドシートの「意見」シートに 1 件 1 行。立場と根拠タイプは必須、主張は 60 字以内。
- 論点の追加・統合・分割はモデレータが行い、「変更履歴」シートに理由を 1 行残す。
- 削除・訂正の申請は Issues またはメンバー経由で。本人からの申請は即時に対応する。
